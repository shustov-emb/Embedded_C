# Статическая библиотека "калькулятор".

## Сборка и запуск

Для управления проектом используйте следующие команды `make`:

*   **`make`** (или `make all`) — Сборка проекта. Компилирует объектные файлы, создает статическую библиотеку `lib/libcalc.a` и собирает исполняемый файл `runner`.
*   **`make run`** — Компиляция и автоматический запуск программы.
*   **`make clean`** — Очистка: удаляет директории `obj/`, `lib/` и исполняемый файл `runner`.

## Структура проекта

*   `src/` — исходные файлы проекта (`.c`).
*   `include/` — заголовочные файлы (`.h`).
*   `obj/` — временные объектные файлы (создается при сборке).
*   `lib/` — скомпилированная статическая библиотека (создается при сборке).
