# Задание 11 (Потоки)
Реализуйте многопоточное приложение, моделирующее работу сети из 5 магазинов. Система должна включать
три потока покупателей с начальной потребностью 9900–10100 единиц и один поток погрузчика, пополняющий случайный отдел на 200 единиц каждые 2 секунды. Доступ к каждому отделу должен строго регулироваться индивидуальным мютексом (взаимное исключение покупателей и погрузчика); опционально допускается использование condition variables. Покупатель должен обходить свободные отделы, обнуляя их остатки до полного удовлетворения своей потребности, засыпая на 2 секунды при пустых полках. Программа обязана логировать в консоль каждое действие потоков (вход в отдел, изменение остатков, сон) и корректно завершать все потоки после насыщения всех покупателей.

## Сборка и запуск

Для управления проектом используйте следующие команды `make`:

*   **`make`**                  — Сборка проекта. Компилирует объектные файлы и собирает исполняемый файл `run`.
*   **`make run`**              — Компиляция и автоматический запуск c mutex.
*   **`make m_run/s_run`**      — Компиляция и автоматический запуск програму mutex/spinlock. 
    (пример `make s_run`)
*   **`make valgrind prog=mutex/spinlock`** — Запускает программу mutex/spinlock с valgrind 
    (пример `make valgrind prog=mutex`).
*   **`make helgrind prog=mutex/spinlock`** — Запускает программу mutex/spinlock с helgrind. 
    (пример `make helgrind prog=spinlock`)
*   **`make clean`**    — Очистка: удаляет директории `obj/`, `bin/` вместе с исполняемым файлом `bin/run`

## Структура проекта

*   `src/`      — Исходные файлы проекта (`.c`).
*   `include/`  — Заголовочные файлы (`.h`).
*   `obj/`      — Временные объектные файлы (создается при сборке).
*   `bin/`      — Сюда ляжет бинарник (создается при сборке).
