# Выпускное задание 2: fork + poll/epoll/select + timers + IPC
Управление такси.

Есть опорный пункт - исходное приложение. Запускается один раз и привязано к терминалу, имеет CLI.

В CLI должны быть команды:
* `create_driver()` - создает новый процесс (driver), который ожидает команд от CLI, pid процесса будет использоваться  для обращения к этому driver.
* `send_task(<pid> <task_timer>)` - создаст задачу для driver номер <pid> и займет его на <task_timer> секунд. 
<br>Eсли попытаться обратиться к этому driver во время выполнения задания с помощью send_task, то driver должен послать ошибку Busy <task_timer>. 
<br>По истечению <task_timer> секунд driver меняет свое состояние на Available.
* `get_status(<pid>)` - показывает статус driver с номером <pid>. Может быть Busy <task_timer> либо Available.
* `get_drivers` -  показывает статусы и pid всех drivers запущенных из этого инстанса CLI.

## Сборка и запуск

Для управления проектом используйте следующие команды `make`:

*   **`make`**      — Сборка проекта. Компилирует объектные файлы и собирает исполняемый файл `run`.
*   **`make run`**  — Компиляция и автоматический запуск программы.
*   **`make clean`**    — Очистка: удаляет директории `obj/`, `lib/`, `bin/` вместе с исполняемым файлом `bin/run`

## Структура проекта

*   `src/`      — Исходные файлы проекта (`.c`).
*   `include/`  — Заголовочные файлы (`.h`).
*   `obj/`      — Временные объектные файлы (создается при сборке).
*   `bin/`      — Сюда ляжет бинарник (создается при сборке).
