# Задание 6. Двусвязный список и список абонентов

## Сборка и запуск

Для управления проектом используйте следующие команды `make`:

*   **`make`** (или `make all`) — Сборка проекта. Компилирует объектные файлы и собирает исполняемый файл `runner`.
*   **`make run`** — Компиляция и запуск программы.
*   **`make clean`** — Очистка: удаляет директорию `obj/` и исполняемый файл `runner`.
*   **`make valgrind`** — Запуск программы через `Valgrind` для проверки утечек памяти.

## Структура проекта

*   `src/` — исходные файлы проекта (`.c`).
*   `include/` — заголовочные файлы (`.h`).
*   `obj/` — временные объектные файлы (создается при сборке).
