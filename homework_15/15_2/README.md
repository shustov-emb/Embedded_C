# 15.2 sigprocmask

Реализовать программу, которая будет блокировать сигнал SIGINT с помощью вызова sigprocmask() и уходить в бесконечный цикл.  

Проверить работу программы с помощью второй программы из задания 1 и утилиты  kill.

*Дополнительная программа и её исходный код лежат в /homework_15, программа принимает два параметра целочисленный сигнал и целочисленный pid*

---

Для управления проектом используйте следующие команды `make`:

*   **`make`**          — Сборка проекта. Компилирует объектные файлы и собирает исполняемый файл `run`.
*   **`make run`**      — Компиляция и автоматический запуск программы.
*   **`make valgrind`** — Запускает программу с valgrind.
*   **`make clean`**    — Очистка: удаляет директории `obj/`, `lib/`, `bin/` вместе с исполняемым файлом `bin/run`

## Структура проекта

*   `src/`      — Исходные файлы проекта (`.c`).
*   `include/`  — Заголовочные файлы (`.h`).
*   `obj/`      — Временные объектные файлы (создается при сборке).
*   `bin/`      — Сюда ляжет бинарник (создается при сборке).
