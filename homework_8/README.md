# Динамическая библиотека "калькулятор".

## Сборка и запуск

Для управления проектом используйте следующие команды `make`:

*   **`make`** (или `make all`) — Сборка проекта. Компилирует объектные файлы, создает динамическую библиотеку `lib/libcalc.so` и собирает исполняемый файл `runner`.
*   **`make run`** — Компиляция (с подключением динамической библиотеки) и автоматический запуск программы.
*   **`make run_plugin`** — Компиляция (через плагин -ldl) и автоматический запуск программы.
*   **`make clean`** — Очистка: удаляет директории `obj/`, `lib/` и исполняемый файл `runner` и `runner_plugin`.

## Структура проекта

*   `src/` — исходные файлы проекта (`.c`).
*   `include/` — заголовочные файлы (`.h`).
*   `obj/` — временные объектные файлы (создается при сборке).
*   `lib/` — скомпилированная динамическая библиотека (создается при сборке).
