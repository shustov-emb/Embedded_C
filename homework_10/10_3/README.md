# Задание 10.3 (Процессы)
Реализовать аналог командного интерпретатора bash. При запуске программы пользователю предлагается ввести имя программы и опции запуска программы. Программа порождает процесс и в нем выполняет введенную программу с заданными опциями, ждет завершения дочернего процесса. Снова возвращается к вводу следующей программы. Выход из интерпретатора по команде **exit**.

Задание с заковырочкой! Долго искал причину возможных утечек черз valgrind. В итоге понял что надо быть осмотрительней, и даже если порождённый нами процесс вернул ошибку, тут тоже необходимо память высвобождать! 
Ну и в целом почему-то забывал высвобождать память в цикле при получении неверных данных от `GetCommand()` и при выходе через **exit**, хотя это было очевидно!

Решил запускать программы через `execvp`, просто передаём имя программы и праметры массивом, которые парсим через `strtok`.

## Сборка и запуск

Для управления проектом используйте следующие команды `make`:

*   **`make`**          — Сборка проекта. Компилирует объектные файлы и собирает исполняемый файл `run`.
*   **`make run`**      — Компиляция и автоматический запуск программы.
*   **`make valgrind`** — Запускает программу с valgrind.
*   **`make clean`**    — Очистка: удаляет директории `obj/`, `lib/`, `bin/` вместе с исполняемым файлом `bin/run`

## Структура проекта

*   `src/`      — Исходные файлы проекта (`.c`).
*   `include/`  — Заголовочные файлы (`.h`).
*   `obj/`      — Временные объектные файлы (создается при сборке).
*   `bin/`      — Сюда ляжет бинарник (создается при сборке).
